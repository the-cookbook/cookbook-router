# Changelog

Package changelogs are generated by Changesets during release versioning. Before the first published release, see `.changeset/` for pending release notes.

## Table of contents

- [Release candidate](#release-candidate)
- [Where package changelogs come from](#where-package-changelogs-come-from)

## Release candidate

The release candidate is gated by `pnpm test:ci`, which validates formatting, release metadata, type checking, linting, package coverage, examples, repository E2E tests, builds, npm dry runs, and the external consumer trial app.

## Where package changelogs come from

Package-specific changelogs are generated by Changesets during release versioning. Add user-visible package changes with:

```sh
pnpm changeset
```

Pending release notes live under `.changeset/` until the versioning workflow converts them into package changelogs.
